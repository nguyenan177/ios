Cài đặt qua TrollStore Tải file .tipa
Trước khi cài: mở TrollStore → Settings → bật "Enable URL Scheme".

Nhấn "Cài đặt qua TrollStore" sẽ tự mở TrollStore và bắt đầu tải + cài. Nếu không thấy TrollStore bật lên, dùng nút "Tải file .tipa" rồi mở bằng TrollStore thủ công.
